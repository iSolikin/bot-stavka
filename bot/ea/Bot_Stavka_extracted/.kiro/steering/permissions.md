# Разрешения для проекта Bot_Stavka

Владелец проекта дал полное согласие на все действия в рамках проекта `d:\Bot_Stavka`.

## Что разрешено без дополнительных подтверждений

- Создавать, редактировать, удалять любые файлы внутри `d:\Bot_Stavka`
- Устанавливать зависимости из `requirements.txt`
- Создавать и изменять конфигурационные файлы (кроме `.env` с реальными секретами)
- Запускать команды сборки, линтинга, тестов
- Создавать Docker-файлы и конфигурации
- Рефакторить и переписывать любые модули проекта
- Принимать архитектурные решения в рамках плана `esports-bot-plan.md`

## Стиль работы

- Действовать автономно, не спрашивать подтверждения на каждый шаг
- Сообщать что сделано — кратко, по факту
- Уточнять только если задача принципиально выходит за рамки плана
