# Шаблоны для farm_bot

Сюда нужно положить два файла-картинки, вырезанные из игры:

| Файл            | Что вырезать                                       |
|-----------------|----------------------------------------------------|
| `tree.png`      | Одно заснеженное дерево (крона, без лишнего фона)  |
| `ore.png`       | Одна кучка руды (тёмные камни)                     |
| `wood_drop.png` | Связка брёвен, лежащая на земле (лут после рубки)  |
| `ore_drop.png`  | Кусок руды на земле (лут после добычи)             |

Лут-шаблоны необязательны: без них бот просто не будет подбирать лут.
С ними — подбирает лут в первую очередь, как только тот появился.

## Как сделать

1. Открой игру на весь экран (масштаб браузера ровно **100%**).
2. Нажми `Win + Shift + S` — выбери прямоугольник вокруг одного дерева.
3. Вставь в Paint (`Ctrl+V`) и сохрани как `tree.png` в эту папку.
4. Повтори для руды → `ore.png`.

Важно: скриншот должен быть с **того же масштаба/разрешения**, на котором будет
работать бот — иначе шаблон не совпадёт. Если бот не находит цели, попробуй
уменьшить `CONFIDENCE` в `farm_bot.py` с 0.80 до 0.70.
